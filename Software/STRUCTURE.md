# Software/

> 自研电脑端/移动端/云端软件工程（参考结构，工程可自行调整；内部结构由各工程自定）。

## 目录结构

```text
Software/
├── PC_Software/      电脑端应用工程（占位，工程落地时自行改名）
├── Mobile_Software/  移动端应用工程（占位，工程落地时自行改名）
├── Server/      云端服务工程（按需）
└── Common/      共享库（协议编解码等，按需）
```

## 规则

- 自研电脑端/移动端软件工程归本目录；第三方工具配置归 Tools/；
- 自研 OTA 升级服务/工具 → 对应工程（或独立工程）；第三方 OTA 工具配置 → Tools/OTA_Tool/；
- 协议以 Docs/Design/Protocol/ 为准，双端共用实现（优先代码生成）。
